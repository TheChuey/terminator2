 1. THE ONE BIG CHANGE (summarized)
=================================================================
A full visual "face lift" of BOTH user-facing pages plus a real dark
theme, per the user's choices (light + dark toggle, full component
refresh, green/teal accent over the blue base):

  - THEME SYSTEM. Appearance now stores light / dark / system ("system"
    follows the OS via prefers-color-scheme). Both pages set
    data-theme on <html>; every component reads the palette through
    CSS variables, and each page has a [data-theme="dark"] override
    block, so the entire UI re-skins without any markup-level changes.
  - APPEARANCE SECTION grows a "Theme" select (Light / Dark / System),
    with live preview on change; saved to the existing merging
    POST /api/settings. localStorage caches the theme for pre-paint
    application to avoid a light-flash for dark users.
  - PALETTE. New token set: blue base (#0b6bcb) with a branded
    green/teal accent (#0d9488 / #2dd4bf in dark) used for highlights,
    active states, chat agent avatars and gradients. Larger radii
    (small 6 / medium 10 / large 16 / pill) and soft layered shadows.
  - COMPONENTS. Index gets a gradient hero header, card monogram
    avatars with hover lift + teal accent edge, gradient buttons,
    teal focus rings, pill status dots, section-heading accent tiles,
    themed scrollbars. chat.html gets a gradient top bar, welcome
    hint chips, teal/soft user bubbles, accent agent bubbles with
    gradient avatars, a pill gradient composer + gradient Send button,
    and an accent-tinted right panel.

 4. FILE: static/index.html                    (CHANGED - THIS ROUND)
=================================================================
Only one addition: a pre-paint theme script in <head> before the
stylesheet link:

    <script>
        (function () {
            var s = "system";
            try { s = localStorage.getItem("appearance-theme") || "system"; } catch (e) {}
            var dark = window.matchMedia("(prefers-color-scheme: dark)").matches;
            document.documentElement.dataset.theme =
                s === "dark" || s === "light" ? s : (dark ? "dark" : "light");
        })();
    </script>

It flips data-theme before CSS applies so dark users don't see a light
flash; app.js re-applies the authoritative server settings on boot.
